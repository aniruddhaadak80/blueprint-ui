# Technical UI

> A sophisticated design system inspired by technical blueprints and high-end wireframes.

![License](https://img.shields.io/badge/license-MIT-green)
![Version](https://img.shields.io/badge/version-2.4.0-blue)

## ✨ Features

- **48+ Components** — Production-ready, accessible UI components
- **Technical Aesthetic** — Hairline borders, mosaic backgrounds, flat design
- **Design Tokens** — CSS custom properties for seamless theming
- **TypeScript Ready** — Full type definitions included
- **WCAG 2.1 AA** — Built-in accessibility support
- **< 5kb Gzipped** — Tree-shakeable, lightweight bundle

## 🎨 Design Principles

| Principle | Implementation |
|-----------|----------------|
| **Flat Design** | No shadows, 0-2px border-radius only |
| **Hairline Borders** | 1px lines at 20% opacity |
| **Typography** | Space Grotesk (display), JetBrains Mono (labels) |
| **Color Palette** | Paper (#F7F7F5), Forest (#1A3C2B), Coral, Mint, Gold |
| **Image Treatment** | `mix-blend-mode: luminosity` with hover reveal |

## 🛠️ Customization

Override CSS custom properties to match your brand:

```css
:root {
  --paper: #F7F7F5;     /* Background */
  --forest: #1A3C2B;    /* Primary */
  --coral: #FF8C69;     /* Accent 1 */
  --mint: #9EFFBF;      /* Accent 2 */
  --gold: #F4D35E;      /* Accent 3 */
}
```
